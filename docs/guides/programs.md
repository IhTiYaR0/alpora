# Программы и службы ALPORA

Инвентаризация кода и установленной среды: 22 октября 2026 года.
`poly-shell doctor` проверяет наличие программ по функциям. Наличие исполняемого
файла не означает, что устройство доступно, служба запущена или есть разрешения.
Названия пакетов ниже относятся к Arch Linux. Полный `./install.sh` устанавливает
их явный список; компонентная команда `poly-shell install` пакеты не устанавливает.
Сочетания ниже соответствуют поставляемой сессии `integrations/alpora-session.lua`:
личная конфигурация пользователя может отличаться.

## Приложения пользователя

| Назначение | Что используется | Как запускается |
| --- | --- | --- |
| Файловый менеджер | **Nautilus** | Super+E: `nautilus --new-window` |
| Кнопка «Файлы» в календаре | Системный обработчик папок | `xdg-open "$HOME"`; определяется отдельно от Super+E через `xdg-mime query default inode/directory` |
| Терминал | **Foot**, дополнительно **Kitty** | Полная сессия: Super+Return и Super+Q открывают Foot. Kitty устанавливается как дополнительный терминал; команды оболочки задаются в `settings.json` → `apps` |
| Запуск приложений | Встроенный запускатель ALPORA | Super+R и кнопки панели/дока. Fuzzel остаётся внешней альтернативой в конфигурации |
| Звук | Встроенные регуляторы + **Pavucontrol** | Super+A открывает Pavucontrol |
| Сеть | Встроенный Wi-Fi + **Nmtui**, **nm-connection-editor** | Nmtui для расширенного подключения; Super+N — графический редактор |
| Bluetooth | Встроенный список + **Bluetoothctl** | Новое сопряжение с PIN выполняется в терминале |
| Блокировка | **Hyprlock** | Super+L; оформление синхронизируется с темой |
| Выход и питание | Панель ALPORA + **Hyprshutdown** | Super+Shift+E открывает Hyprshutdown |
| Снимки экрана | **Grim + Slurp + wl-copy + notify-send** | Print и кнопка снимка вызывают существующий `$XDG_CONFIG_HOME/hypr/screenshot.sh` |
| Музыка | Любой плеер с **MPRIS** | Виджеты подключаются напрямую через D-Bus; отдельный проигрыватель проект не устанавливает |
| Браузер и редактор | **Firefox**, выбранный редактор | Полная установка включает Firefox (Super+B). Редактор кода и другие браузеры устанавливаются пользователем |

Обработчик папок может отличаться от Nautilus. Редактор сочетаний не меняет
системные приложения по умолчанию. Команды запуска задаются в разделе
«Горячие клавиши»; команды оболочки — также в `settings.json` → `apps`.

## Основа окружения

| Программа / пакет | Назначение |
| --- | --- |
| **Hyprland / hyprctl** | Композитор Wayland, окна, столы, сочетания и события |
| **Quickshell, Qt 6** | QML-интерфейс панели, настроек, виджетов и робота |
| **Python 3** | CLI, сохранение настроек, адаптеры и ALPORA Fetch; без npm-сборки |
| **ALPORA Fetch** | Поставляется в `bin/alpora-fetch`, после установки — `~/.local/bin/alpora-fetch`. Цвета открытой карточки меняются вместе с темой |
| **systemd --user** | Служба оболочки, отдельный процесс настроек, журналы и перезапуск |
| **glib2 / gdbus** | Подписки на D-Bus: уведомления Mako и сон/пробуждение |
| **libxkbcommon** | Проверка названий клавиш редактором сочетаний; также зависимость графического стека |
| **python-pillow / Pillow** | Импорт растровых обоев, извлечение палитры и подготовка изображений Timeline |

Проверенная локальная основа: Arch Linux, Hyprland 0.56.2, Quickshell 0.3.2,
Qt 6.12.0. Редактор сочетаний рассчитан на конфигурацию `hyprland.lua`.
Это описание проверенной среды, а не гарантия совместимости с любой версией.

## Системные интеграции

| Программа / служба | Функция |
| --- | --- |
| **PipeWire + WirePlumber**, `wpctl` | Аудиоустройства, громкость и микрофон |
| **UPower** | Заряд, питание от батареи и состояние зарядки |
| **NetworkManager**, `nmcli`, `nmtui` | Сети и расширенная настройка подключения |
| **BlueZ**, `bluetoothctl` | Bluetooth и сопряжение |
| **util-linux / rfkill** | Программные и аппаратные блокировки радиоустройств |
| **brightnessctl** | Подсветка экрана при наличии устройства и разрешений |
| **power-profiles-daemon / powerprofilesctl** | Профили питания при поддержке оборудования |
| **hyprsunset** | Температура экрана / ночной свет |
| **Mako / makoctl** | Уведомления, история и режим «Не беспокоить» |
| **wl-clipboard / wl-copy, wl-paste** | Копирование, снимки и локальная история буфера |
| **playerctl** | Мультимедийные клавиши поставляемой сессии; виджеты используют MPRIS напрямую |
| **swaybg** | Статические обои; Timeline использует собственную поверхность Quickshell |
| **hypridle** | Поставляемая конфигурация бездействия и блокировки |
| **hyprpolkitagent** | Агент запросов системных разрешений; запускается полной сессией |
| **xdg-desktop-portal + xdg-desktop-portal-hyprland** | Порталы приложений и захват экрана; часть сеанса, не интерфейса Poly Shell |
| **gsettings** | Согласование темы GTK, значков и курсоров |
| **xdg-utils**, **xdg-user-dirs** | Открытие папок и определение каталога изображений для снимков (`xdg-user-dir`) |
| **Waybar** | Только необязательная передача управления от старого окружения через `poly-shell activate`; полный `install.sh` её не устанавливает |

## Разработка и проверки

- `python3`: автоматические тесты стандартной библиотеки `unittest`.
- **Node.js** (`node`): симуляции JavaScript-логики; npm-пакеты не нужны.
- **qt6-declarative / qmllint**: проверка всех QML-файлов.
- **qt6-shadertools / qsb**: пересборка шейдеров при изменении их исходников.
- **Git**: исходники и подготовка релизов.
- **ydotool + ydotoold**: только явные автоматические проверки реального ввода,
  не зависимость обычной работы.
- Foot/Kitty и Grim используются отдельными интеграционными проверками.

`./scripts/check` теперь требует Node.js и QML linter заранее, чтобы отсутствие
инструмента не превращалось в незаметный пропуск JavaScript-проверок.
