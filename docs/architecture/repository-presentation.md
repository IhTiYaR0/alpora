# ALPORA — оформление публичного репозитория

Референсы изучены 22 октября 2026 года. Первоначальная концепция ниже
сохранена как запись исследования. Затем выбрано публичное название ALPORA,
созданы README на английском и русском, векторная обложка и настоящие снимки
в `docs/media/`. Публичный репозиторий: [IhTiYaR0/alpora](https://github.com/IhTiYaR0/alpora).
Техническое имя `poly-shell` сохранено для совместимости команд и настроек.

## Визуальное направление

Горные грани, тёмный фон, тёплый свет и сдержанный шалфейный акцент.
Верхняя иллюстрация использует собственную альпийскую тему; галерея показывает
остальные темы как равноправные варианты. Логотип строится на существующем
горном знаке. Робот — маленькая подпись проекта рядом с основным интерфейсом.

Оформление относится к документации и не меняет палитры или настройки оболочки.
Картинки, интервалы, подписи и навигация должны выглядеть согласованно на GitHub
при светлой и тёмной теме. Макет опирается на Markdown и поддерживаемый HTML,
без зависимости от произвольного CSS.

## Последовательность главной страницы

1. Баннер: горный знак, **POLY SHELL**, подпись
   **A landscape-inspired desktop shell for Hyprland.**
2. Навигация: **Preview · Features · Installation · Documentation**.
   Ниже небольшой ряд достоверных меток платформы, технологии и статуса выпуска.
3. Один большой актуальный снимок окружения. Следом короткое видео с открытием
   панелей, переключением тем, обзором рабочих столов и движением робота.
4. Галерея с единым масштабом и подписями: рабочий стол, настройки, темы,
   обзор рабочих столов. Изображения должны показывать опубликованную версию.
5. Шесть коротких описаний: согласованные темы; панель и быстрые настройки;
   запускатель и док; обзор рабочих столов; виджеты; робот и редактор клавиш.
6. Требования и установка с рабочими командами, затем ссылки на настройку,
   обновление, восстановление, программы, ограничения и помощь.
7. Вклад в проект, благодарности и выбранная лицензия.

Основной README — английский; русский вариант доступен заметной ссылкой рядом
с названием. Подробное текущее описание функций сохраняется в документации.

## Материалы для оформления

- Отдельный векторный баннер, который не имитирует снимок готового интерфейса.
- Актуальные снимки без личных окон, уведомлений и данных буфера обмена.
- Короткая настоящая запись экрана с обложкой для README.
- Одинаковые поля и подписи у кадров; достаточно четырёх основных изображений.
- Обложка для превью ссылки на репозиторий в социальных сетях.

Имеющиеся файлы `assets/reference/*approved*` и `*proposal*` сначала необходимо
отличить от снимков реализации. Концепт не выдаётся за работающую функцию.

## Признаки аккуратного выпуска

Рабочие ссылки, согласованные названия, краткое About, релевантные темы
репозитория, понятная установка, список используемых программ, журнал изменений
и формы сообщений об ошибках. Бейдж проверки добавляется после настройки
настоящего CI. Звёзды, скачивания и результаты тестов не изображаются выдуманными
числами. Название Stable не используется до соответствующей проверки выпуска.

Перед публикацией требуется выбрать лицензию и подтвердить права на включённые
материалы. Придуманные способы установки и неподдерживаемые платформы не
добавляются ради оформления.
