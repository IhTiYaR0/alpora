# Сглаживание робота — 22 октября 2026

Нативный Quickshell на текущем Hyprland, один eDP-1, 1920×1080, scale 1,
60 Hz, Work, forest-mist, reduced motion выключен. Измеряется **весь процесс
оболочки**, не отдельный компонент. CPU — процент одного ядра; это не FPS.

Варианты менялись последовательно в одном процессе с перезагрузкой QML.
Baseline — прежние NumberAnimation у плеч, наклона и flightBlend, прежний
интервал таймера. Optimized — CompanionTween от существующей фазы, с 16 ms
для непрерывно движущихся рук. SHA-256 исходников сохранены в JSON.
Векторные пути, цвета материалов и типы рендерера сравнены с исходником и
сохранены. Опытные варианты скрытия рисунка, удаления сглаживания и замены
CurveRenderer на GeometryRenderer не входят в финальный код.

Приветствие удерживалось IPC-вызовом greet каждые 800 ms, полёты были
выключены. Каждая выборка CPU длится 8 секунд. Полёт задан через
visitSurface floor из одинакового положения на баре; выборка 4 секунды,
в начале и конце робот в fly. Счётчики читались `scripts/check-render-load`.
Настройки полётов восстановлены, файлы оставлены в варианте optimized.

| Условия | До, CPU одного ядра | После, CPU одного ядра |
| --- | ---: | ---: |
| Приветствие, все виджеты перекрыты, 2 повтора | 40.55 / 40.32% | 11.70 / 11.45% |
| Полёт, все виджеты перекрыты, 1 пара | 44.22% | 16.15% |
| Приветствие, все виджеты видны, 1 пара | 37.70% | 38.46% |
| Полёт, все виджеты видны, 1 пара | 38.77% | 39.54% |

[load.json](load.json) содержит исходные и оптимизированные выборки при
перекрытых виджетах. Последняя baseline-выборка полёта прервана сменой
рабочего стола и помечена validContext=false. Следующая optimized-выборка
уже с видимыми виджетами: она **не образует сравнимую пару** с предыдущей
и не включена в первую строку полёта таблицы.

[load-exposed.json](load-exposed.json) отдельно повторяет обе пары на столе
с открытыми виджетами. Все эти контексты стабильны; улучшение CPU там не
подтверждено. Это оставшийся источник нагрузки, требующий отдельного разбора.

Сравнение ограничено короткими выборками на одном компьютере. RSS после
многих QML-перезагрузок не используется для вывода об утечках. Длительного
прогона, измерения мощности и проверки других GPU в этой работе не было.

Проверки финальной версии: 176 тестов и строгий QML lint; нативный
check-companion-input --live прошёл все проверки захвата, бросков, повторного
захвата, отключения во время жеста и ввода в календарь вне робота.
